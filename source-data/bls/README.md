# BLS source files

bls.gov blocks downloads from cloud servers, so the two BLS files the career list is built from are kept here. Replace them once a year when BLS releases new data (wages each spring, projections each fall). The GitHub Action picks them up automatically.

- `oesm24nat.zip` — OEWS national wages. https://www.bls.gov/oes/tables.htm → National → XLS
- `occupation.xlsx` — Employment Projections. https://www.bls.gov/emp/ind-occ-matrix/occupation.xlsx
